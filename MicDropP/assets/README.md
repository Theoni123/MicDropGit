# Assets Directory

## Background Image

Place your background image here with one of these names:
- `background.jpg` or `background.jpeg`
- `background.png`
- `background.webp`
- `bg.jpg`, `bg.png`, etc.
- `background-image.jpg`, etc.

The app will automatically detect and use this image as the background.

### Supported Formats:
- JPG/JPEG
- PNG
- WebP

### Recommended:
- High resolution (1920x1080 or larger)
- Optimized file size for web (< 2MB recommended)
- The image will be automatically converted to base64 and embedded in the CSS

### How to Add Your Image:

1. Save your image file to this `assets/` folder
2. Name it `background.jpg` (or `.png`, `.webp`)
3. Restart your Streamlit app
4. The image will automatically appear as the background!

**Note:** If no image is found, the app will use a purple gradient background as a fallback.
